Get started

Install in a minute

InstaSpace isn't in the App Store, Microsoft Store or Google Play, so each system asks once before opening it.

💻

Mac

  1. Open InstaSpace-1.2.dmg, drag the app to Applications.
  2. First launch: System Settings → Privacy & Security → Open Anyway.
  3. Later versions: InstaSpace → Check for Updates…
Download for Mac
⊞

Windows

  1. Run InstaSpace-Setup-1.2.0.exe.
  2. If SmartScreen appears: More info → Run anyway.
  3. It updates itself from Settings → Updates.
Download for Windows
🤖

Android

  1. Download InstaSpace-1.2.apk on your phone and open it.
  2. Allow Install unknown apps for your browser when asked.
  3. Share a link from Instagram or X straight into InstaSpace.
Download APK
📱

iPhone & iPad

  1. Download InstaSpace-1.2-unsigned.ipa on a computer.
  2. Install it with Sideloadly or AltStore, which sign it with your Apple ID.
  3. With a free Apple ID, re-install every 7 days.
Download .ipa
Downloads stay on your device: Downloads/InstaSpace on Mac and Windows, Download/InstaSpace on Android, and Files → On My iPhone → InstaSpace on iPhone. YouTube on Mac and Windows uses the open-source yt-dlp engine, which installs from inside the app on first use.
InstaSpace is an independent app and isn't affiliated with Instagram, Meta, X or YouTube.
